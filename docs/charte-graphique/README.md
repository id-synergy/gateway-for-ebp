# Charte graphique — Gateway EBP

Référence visuelle de la **Gateway EBP** : couleurs, typographie, logo, formes et
trames. Sert à habiller toute surface de l'écosystème (back-office web, applications
mobiles compagnon, documents) de façon cohérente.

Produit open source générique : **aucune référence à un client ou à un intégrateur**
ne doit apparaître dans ces assets.

## Sommaire

- [`couleurs.md`](couleurs.md) — palette, rôles, valeurs HEX / OKLCH, clair et sombre.
- [`typographie.md`](typographie.md) — police, tailles, graisses, usages.
- [`logo.md`](logo.md) — logo gateway, construction, déclinaisons, zone de respiration.
- [`formes-et-trames.md`](formes-et-trames.md) — rayons, cartes, ombres, états, boutons.
- [`application-mobile.md`](application-mobile.md) — adaptation iOS (Liquid Glass) et logo
  d'app dédié « base article ».

## Les trois couleurs qui identifient la gateway

| Rôle | Couleur | HEX |
|------|---------|-----|
| Accent / action | Bleu électrique | `#0046FE` |
| Texte / profondeur | Marine | `#002C52` |
| Fond chaleureux | Crème | `#F6F2E4` |

Tout le reste (gris, états, bordures) en découle. Voir [`couleurs.md`](couleurs.md).
